# hr_attendance_odoo17
HR Attendance Module Inherit for Odoo 17

A custom Odoo 17 module that streamlines attendance management by importing employee attendance data from Excel files (.xls).

Key Features:

* Bulk attendance import from Excel spreadsheets
* Automatic creation of attendance records
* Late time calculation based on employee work schedules
* Improved efficiency for HR operations
* Easy integration with existing Odoo HR workflows

Technologies:

* Odoo 17
* Python
* XML
